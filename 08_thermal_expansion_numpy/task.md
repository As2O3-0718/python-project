# 项目 08：热膨胀测量 NumPy 分析

## 今日目标

使用 NumPy 二维数组保存多件试样在不同温度下的长度测量值，通过索引、切片、广播和向量化运算计算热膨胀结果。

## 知识点

- NumPy 一维与二维数组
- 数组的 `shape`、索引和切片
- 广播与向量化运算
- 按轴进行平均值和标准差统计
- 布尔数组与条件筛选
- NumPy 数组形状验证

## 明确任务

1. 使用 NumPy 创建温度数组 `temperatures`：

   ```text
   [20, 50, 80, 110, 140]
   ```

2. 创建试样编号数组 `sample_ids`，内容为 `S1`、`S2`、`S3`、`S4`；再创建二维长度数组 `lengths_mm`，每行对应一件试样，每列对应一个温度，数据如下，单位为 mm：

   ```text
   S1: 50.000, 50.018, 50.036, 50.054, 50.072
   S2: 49.980, 49.997, 50.015, 50.032, 50.050
   S3: 50.020, 50.036, 50.053, 50.069, 50.086
   S4: 50.010, 50.031, 50.051, 50.072, 50.092
   ```

3. 在终端输出 `temperatures` 和 `lengths_mm` 的形状，并输出 `S2` 的全部长度、所有试样在 80 °C 时的长度。以上数据必须通过数组索引或切片取得，不能重新手写数值。
4. 计算每个温度相对于 20 °C 的温差数组，公式为：

   ```text
   温差 = 当前温度 - 20 °C
   ```

5. 计算每件试样相对于自身 20 °C 初始长度的长度变化量，得到一个与 `lengths_mm` 形状相同的二维数组。不得使用循环逐个元素计算。
6. 计算每件试样在 140 °C 时的平均线膨胀系数：

   ```text
   线膨胀系数 = (140 °C 时长度 - 20 °C 时长度) / (20 °C 时长度 × 温差)
   ```

   结果单位为 `1/°C`。将结果乘以 `1_000_000`，以 `10⁻⁶/°C` 为显示单位，并在终端逐行输出四件试样的结果，保留三位小数。
7. 使用 NumPy 计算四件试样线膨胀系数的平均值和总体标准差。总体标准差使用 NumPy 的默认定义，不进行样本标准差修正。
8. 以 `10.500 × 10⁻⁶/°C` 到 `13.000 × 10⁻⁶/°C` 为合格范围，边界值也算合格。使用布尔数组筛选并输出所有合格试样编号及其线膨胀系数。
9. 沿正确的轴计算每个温度下四件试样的平均长度，输出五个温度对应的结果，保留三位小数。
10. 数值计算部分必须使用 NumPy 向量化运算；允许使用循环完成逐行终端输出，但不得用循环逐项计算长度变化量、线膨胀系数、平均值或标准差。
11. 将主要分析过程放入一个函数中。函数至少检查以下情况，条件不满足时抛出 `ValueError`：
    - `temperatures` 不是一维数组；
    - `lengths_mm` 不是二维数组；
    - 长度数组的列数与温度数量不一致；
    - 试样编号数量与长度数组的行数不一致；
    - 温度少于两个，或温度没有严格递增；
    - 任一试样在第一个温度下的初始长度不大于 0。

## 验收标准

- 正确创建一维温度数组、试样编号数组和形状为 `(4, 5)` 的二维长度数组。
- 能正确使用 `shape`、行切片和列切片取得指定数据。
- 温差和长度变化量的形状、数值正确，并由向量化运算得到。
- 四件试样的线膨胀系数、平均值和总体标准差正确，显示单位与小数位数正确。
- 合格范围包含上下边界，布尔筛选结果正确。
- 每个温度下的平均长度沿正确的轴计算，结果保留三位小数。
- 数值统计没有使用手写循环逐项累加。
- 所有指定的异常形状、数量、温度和初始长度测试都会抛出 `ValueError`。
- 代码使用清晰的 `snake_case` 命名，并将分析过程组织在函数中。
