# 项目 04：拉伸实验批次汇总

## 今日目标

使用字典保存多组拉伸实验记录，完成批次级别的统计与筛选，并输出清晰的实验摘要。

预计用时：30–45 分钟。

## 知识点

- 字典的键和值
- 由字典组成的列表
- `for` 循环遍历结构化数据
- 函数返回统计结果
- 条件筛选与 f-string 输出

## 明确任务

1. 在程序中创建一个名为 `test_records` 的列表，保存以下 5 条拉伸实验记录；每条记录都必须是一个字典：

   | 试样编号 | 批次 | 抗拉强度（MPa） | 断后伸长率（%） |
   | --- | --- | ---: | ---: |
   | S01 | A | 468 | 18.5 |
   | S02 | A | 475 | 17.8 |
   | S03 | A | 459 | 19.2 |
   | S04 | B | 482 | 16.9 |
   | S05 | B | 477 | 17.4 |

2. 编写并调用函数 `summarize_batch(records, batch_name)`。该函数接收全部记录和一个批次名称，返回该批次的试样数量、平均抗拉强度、最高抗拉强度、平均断后伸长率。
3. 分别为批次 A 和批次 B 调用该函数，并输出两份批次摘要。
4. 定义“强度偏低”为抗拉强度小于 465 MPa。遍历全部记录，输出所有强度偏低试样的编号、批次和抗拉强度。
5. 如果没有强度偏低的试样，输出 `没有强度偏低的试样`。
6. 对不存在的批次名称，程序应输出 `没有找到该批次的实验记录`，且不进行平均值计算。

## 示例输入输出

程序使用题目中给出的实验记录。输出格式可以类似：

```text
批次 A
试样数量：3
平均抗拉强度：467.3 MPa
最高抗拉强度：475.0 MPa
平均断后伸长率：18.5 %

批次 B
试样数量：2
平均抗拉强度：479.5 MPa
最高抗拉强度：482.0 MPa
平均断后伸长率：17.2 %

强度偏低试样：S03（批次 A，459.0 MPa）
```

## 验收标准

- `test_records` 中的每一条实验记录均使用字典保存。
- 程序正确筛选指定批次，并计算数量、平均抗拉强度、最高抗拉强度和平均断后伸长率。
- 统计函数被实际调用，且返回值使用清楚。
- 能正确找出抗拉强度小于 465 MPa 的试样。
- 不存在的批次不会导致除零错误或程序崩溃。
- 数值输出保留一位小数，单位与标签清楚。
- 变量和函数命名采用清晰的 `snake_case` 风格，程序可以直接运行。

## 建议文件名

`tensile_batch_summary.py`
