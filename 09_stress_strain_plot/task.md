# 项目 09：拉伸试验应力—应变曲线可视化

## 今日目标

使用 pandas 读取拉伸试验测量数据，利用 NumPy 找到峰值，再用 Matplotlib 在同一坐标轴上绘制两种热处理状态的工程应力—应变曲线。

预计用时：30–45 分钟。

## 知识点

- 使用 pandas 读取 CSV，并取得用于绘图的数据列
- NumPy 数组的峰值索引与对应元素
- Matplotlib 的 `Figure` 和 `Axes`
- 折线、数据点、标题、坐标轴标签、图例和网格
- 标记并注释曲线上的特征点
- 保存 PNG 图像

## 明确任务

1. 读取项目文件夹中已经提供的 `stress_strain.csv`。无论从仓库根目录还是项目文件夹启动程序，都必须能正确找到数据文件。
2. 从 CSV 中取得以下三列，绘图和计算时不得重新手写其中的测量值：
   - `strain_percent`：工程应变，单位为 `%`；
   - `annealed_mpa`：退火态工程应力，单位为 `MPa`；
   - `quenched_tempered_mpa`：调质态工程应力，单位为 `MPa`。
3. 在终端输出读取到的测量点数量。
4. 使用 NumPy 分别找到两条曲线的峰值应力及其对应的工程应变，不得手写峰值或用循环逐项寻找。按示例格式输出结果。
5. 创建一张尺寸为 `8 × 5` 英寸、只含一个坐标轴的图，并在同一坐标轴中绘制两组数据：
   - 退火态使用实线和圆形数据点，图例文字为 `Annealed`；
   - 调质态使用虚线和方形数据点，图例文字为 `Quenched & Tempered`。
6. 两条曲线都必须完整绘出 CSV 中的 11 个测量点，并按工程应变从小到大的顺序连接；不要只绘制峰值或筛选后的数据。
7. 使用单独的散点标记突出两条曲线的峰值，并在峰值附近分别添加文字 `Peak: 385 MPa` 和 `Peak: 600 MPa`。峰值坐标必须来自计算结果。
8. 图中必须包含以下英文文字，以避免依赖额外的中文字体配置：
   - 标题：`Engineering Stress-Strain Curves`
   - 横轴：`Engineering Strain (%)`
   - 纵轴：`Engineering Stress (MPa)`
9. 显示图例和网格；网格应使用虚线并带有透明度，使曲线仍然清楚可见。
10. 调整布局后，将图像保存到项目文件夹中的 `stress_strain_curve.png`，保存分辨率为 `150 dpi`。在终端输出保存成功信息。图像保存后可以自行决定是否显示交互窗口。
11. 将“读取数据”和“绘制图像”至少拆分为两个职责清楚的函数，并使用 `snake_case` 命名。主流程负责调用函数和输出结果。

## 验收标准

- 程序能从不同工作目录启动，并正确读取项目文件夹中的 CSV。
- 三列数据均来自 `stress_strain.csv`，没有在代码中复制整组测量值。
- 使用 NumPy 正确得到 `385 MPa、10.0%` 和 `600 MPa、8.0%` 两组峰值结果。
- 峰值查找没有使用循环逐项比较，也没有硬编码峰值坐标。
- 两条完整曲线绘制在同一个坐标轴中，线型、数据点形状和图例能够区分两种状态。
- 标题、坐标轴名称、单位、网格、图例、峰值标记和峰值文字完整且可读。
- PNG 保存在项目文件夹中，尺寸为 `1200 × 750` 像素，且没有被交互窗口遮挡或保存为空白图。
- 终端输出的文字、顺序、数值和格式与示例一致。
- 读取与绘图职责已合理拆分，变量和函数采用清晰的 `snake_case` 命名。
