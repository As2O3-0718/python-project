# 项目 03：热处理温度报告

## 今日目标

从文本文件读取一组热处理温度数据，使用函数完成数据检查与统计，并在屏幕上生成一份简短报告。

预计用时：30–45 分钟。

## 知识点

- 使用 `with open(...)` 读取文本文件
- 将字符串转换为数值
- 使用列表保存实验数据
- 使用函数拆分程序功能
- 使用循环和条件判断筛选数据

## 明确任务

1. 程序从同一文件夹下的 `temperatures.txt` 读取温度数据。
2. 文件中每行包含一个温度，单位为摄氏度；读取时忽略空行。
3. 将每个有效温度转换为 `float` 并保存到列表中。
4. 至少编写并调用以下两个函数：
   - `read_temperatures(filename)`：读取文件并返回温度列表。
   - `analyze_temperatures(temperatures)`：计算并返回平均温度、最高温度、最低温度和超温次数。
5. 将高于 850 摄氏度定义为超温。
6. 如果文件中没有有效数据，输出 `没有可分析的温度数据`，并结束程序。
7. 输出平均温度、最高温度、最低温度和超温次数；所有温度保留一位小数。
8. 如果没有超温，输出 `本次热处理温度全部合格`；否则输出 `请检查超温记录`。

本项目已经提供 `temperatures.txt`，不要在程序中直接写死这些温度。

## 示例输入输出

使用已提供的数据文件时，输出格式应类似：

```text
温度记录数：6
平均温度：846.7 °C
最高温度：860.0 °C
最低温度：830.0 °C
超温次数：2
请检查超温记录
```

## 验收标准

- 程序确实从 `temperatures.txt` 读取数据，而不是在代码中写死数据。
- 能忽略空行并正确转换有效温度。
- 至少定义并调用指定的两个函数。
- 平均值、最高值、最低值和超温次数计算正确。
- 输出格式清楚，温度保留一位小数并带有单位。
- 能正确处理空文件或只有空行的文件。
- 变量和函数命名清楚，程序可以直接运行。

## 建议文件名

`temperature_report.py`

## 可选挑战

在报告末尾逐条输出超温记录的序号和温度，例如：`第 3 条：855.0 °C`。

请先独立完成。遇到困难时，再打开同目录中的 `hint.md`，并按顺序查看提示。
