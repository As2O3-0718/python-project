# 项目 03：渐进提示

请一次只看一条提示；尝试几分钟后仍然没有思路，再查看下一条。

## 提示 1

在读取函数中使用 `with open(filename, "r", encoding="utf-8") as file:`，然后循环遍历文件。可以先用 `strip()` 去掉每行两端的空白，再判断这一行是否为空。

## 提示 2

分析函数可以先分别计算 `sum(temperatures) / len(temperatures)`、`max(temperatures)` 和 `min(temperatures)`。超温次数可以从 0 开始，在循环中遇到大于 850 的温度时加 1。

## 提示 3

让分析函数一次返回多个结果，例如平均值、最高值、最低值和超温次数；调用函数时，可以用四个变量同时接收这些返回值。
