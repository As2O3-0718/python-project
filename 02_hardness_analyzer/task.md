# 项目 02：维氏硬度数据分析器

## 今日目标

编写一个程序，记录一组材料的维氏硬度测试结果，并计算常用的统计指标。

预计用时：30–45 分钟。

## 知识点

- 使用列表保存一组实验数据
- 使用 `for` 循环重复读取数据
- 使用 `sum()`、`len()`、`max()` 和 `min()`
- 使用条件判断评价数据波动
- 使用 f-string 格式化输出

## 任务要求

1. 让用户输入硬度测量次数 `n`。
2. 如果 `n` 不大于 0，输出 `测量次数必须大于 0`，并结束程序。
3. 使用循环依次输入 `n` 个维氏硬度值，单位为 HV。
4. 如果任意硬度值不大于 0，输出 `硬度值必须大于 0`，并结束程序。
5. 将所有有效的硬度值保存在一个列表中。
6. 计算并输出以下结果：
   - 平均硬度，保留两位小数
   - 最大硬度
   - 最小硬度
   - 极差，即最大值减去最小值
7. 如果极差不大于 10 HV，输出 `测试结果较稳定`；否则输出 `测试结果波动较大`。

## 示例输入输出

```text
请输入测量次数：5
请输入第 1 个硬度值（HV）：205
请输入第 2 个硬度值（HV）：211
请输入第 3 个硬度值（HV）：208
请输入第 4 个硬度值（HV）：206
请输入第 5 个硬度值（HV）：210

平均硬度：208.00 HV
最大硬度：211.0 HV
最小硬度：205.0 HV
极差：6.0 HV
测试结果较稳定
```

## 验收标准

- 能正确读取并保存指定数量的硬度数据。
- 能正确计算平均值、最大值、最小值和极差。
- 平均硬度保留两位小数，所有结果带有单位。
- 能拒绝不大于 0 的测量次数和硬度值。
- 能根据极差正确评价测试结果。
- 变量命名清楚，程序能够直接运行。

`hardness_analyzer.py`
