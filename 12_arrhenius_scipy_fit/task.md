# 项目 12：Arrhenius 扩散系数 SciPy 拟合

## 今日目标

从扩散实验 CSV 中读取不同温度下的扩散系数，使用 Arrhenius 关系完成变量变换，再用 SciPy 进行线性回归，计算扩散活化能、指前因子及活化能的 95% 置信区间。

预计用时：30–45 分钟。

## 知识点

- pandas 读取长表 CSV 与输入数据检查
- Arrhenius 关系和摄氏温度到开尔文温度的换算
- NumPy 的自然对数与指数运算
- `scipy.stats.linregress()` 线性回归
- 回归斜率标准误、t 分布与 95% 置信区间
- Matplotlib 散点图和拟合直线

## 明确任务

1. 使用 pandas 读取项目文件夹中的 `diffusion_data.csv`。无论从仓库根目录还是项目文件夹启动程序，都必须正确找到输入文件；不得在程序中重新手写实验数据。
2. CSV 采用“一条测量记录一行”的长表结构：

    - `sample_id`：测量记录编号；
    - `temperature_c`：实验温度，单位为 `°C`；
    - `diffusion_coefficient_m2_s`：扩散系数，单位为 `m²/s`。

3. 检查输入数据是否包含全部三个必需列。参与拟合的数据至少需要 3 个不同温度点；温度必须高于绝对零度，扩散系数必须大于 0。遇到不满足要求的数据时，应给出清楚的错误信息，而不是继续产生无意义结果。
4. 将摄氏温度换算为开尔文温度，并按以下定义构造 Arrhenius 线性回归变量：

    ```text
    temperature_k = temperature_c + 273.15
    x = 1000 / temperature_k
    y = ln(diffusion_coefficient_m2_s)
    ```

5. 编写一个接收 `x` 和 `y` 一维数组的拟合函数，使用 `scipy.stats.linregress()` 完成线性回归，并通过返回值把回归结果交给主流程。拟合过程中保留原始精度，不得先对变换变量或回归结果进行舍入。
6. Arrhenius 关系为：

    ```text
    D = D₀ × exp(-Q / (R × T))
    ```

    本项目使用气体常数 `R = 8.314 J/(mol·K)`。由于横坐标定义为 `1000 / T`，活化能和指前因子按以下关系计算：

    ```text
    Q = -slope × R
    D₀ = exp(intercept)
    ```

    按此公式得到的 `Q` 数值单位为 `kJ/mol`。
7. 根据回归结果中的斜率标准误计算活化能的双侧 95% 置信区间。自由度为 `n - 2`，其中 `n` 是拟合点数；使用 `scipy.stats.t.ppf()` 得到 t 临界值。先计算活化能的不确定度，再用 `Q - uncertainty` 和 `Q + uncertainty` 得到区间上下限。
8. 按示例格式输出数据点数、摄氏温度范围、回归斜率、回归截距、活化能、活化能 95% 置信区间、指前因子和决定系数 `R²`。格式要求如下：

    - 温度输出为整数；
    - 斜率和截距保留四位小数；
    - 活化能及其区间保留一位小数；
    - 指前因子使用三位小数的科学计数法；
    - `R²` 保留四位小数。

9. 编写绘图函数，创建一张 `8 × 6` 英寸的图：

    - 使用散点表示 6 个变换后的实验点；
    - 使用连续直线表示测量温度范围内的 SciPy 回归结果；
    - 拟合直线的横坐标应按数值顺序排列，不能依赖输入记录原有顺序；
    - 显示虚线网格并设置透明度；
    - 显示两项图例，实验点为 `Measurements`，拟合直线为 `SciPy Linear Fit`。

10. 图标题为 `Arrhenius Plot for Carbon Diffusion`，横轴为 `1000 / Temperature (1/K)`，纵轴为 `ln(Diffusion Coefficient)`。标题、图例、坐标轴文字和数据不得重叠或被裁切。
11. 调整布局后，将图像保存到项目文件夹中的 `arrhenius_fit.png`，分辨率为 `150 dpi`。无论从哪个工作目录启动，图像都必须保存在项目文件夹中；保存后按示例输出成功信息，可以自行决定是否显示交互窗口。
12. 至少将“读取并检查数据”“SciPy 回归与参数计算”和“绘制图像”拆分为职责清楚的函数。分析函数通过 `return` 返回结果，由主流程统一组织终端输出；变量和函数使用清晰的 `snake_case` 命名。

## 验收标准

- 使用 pandas 从长表 `diffusion_data.csv` 读取全部 6 条记录，程序中没有复制输入测量值。
- 程序能从仓库根目录和项目目录启动，并正确找到输入 CSV、将输出 PNG 保存到项目文件夹。
- 正确完成开尔文温度、`1000 / T` 和扩散系数自然对数变换，计算过程中没有提前舍入。
- 使用 `scipy.stats.linregress()` 得到斜率 `-18.2908`、截距 `-10.2877` 和 `R² = 0.9984`。
- 正确得到活化能 `152.1 kJ/mol`、95% 置信区间 `143.7–160.4 kJ/mol` 和指前因子 `3.405e-05 m²/s`。
- 对缺少必需列、少于 3 个不同温度点、温度不高于绝对零度或扩散系数不大于 0 的数据能够给出清楚错误信息。
- 终端输出的文字、顺序、数值和格式与示例一致。
- 图中实验点、回归线、标题、坐标轴名称、图例和网格完整可读，布局没有明显重叠或裁切。
- PNG 保存在项目文件夹中，尺寸为 `1200 × 900` 像素，且不是空白图像。
- 读取、分析和绘图职责合理拆分；分析函数通过返回值提供结果，主流程统一输出，命名清楚。
