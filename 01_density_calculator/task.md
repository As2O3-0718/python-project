# 项目 01：材料密度计算器

## 今日目标

编写一个能够读取试样质量和体积、检查输入并计算密度的 Python 程序。

预计用时：30–45 分钟。

## 知识点

- 使用 `input()` 获取用户输入
- 使用 `float()` 将文本转换为小数
- 使用变量保存数据和计算结果
- 使用 `if` 进行条件判断
- 使用 f-string 格式化输出

## 任务要求

1. 让用户输入试样质量，单位为 g。
2. 让用户输入试样体积，单位为 cm³。
3. 检查质量和体积是否都大于 0。
4. 如果输入有效，按照 `密度 = 质量 / 体积` 计算密度。
5. 输出结果时保留两位小数，并标明单位 `g/cm³`。
6. 如果质量或体积不大于 0，输出提示：`输入数据必须大于 0`。

## 示例输入输出

```text
请输入质量（g）：39.25
请输入体积（cm³）：5
试样密度：7.85 g/cm³
```

无效输入示例：

```text
请输入质量（g）：20
请输入体积（cm³）：0
输入数据必须大于 0
```

## 验收标准

- 正数输入可以得到正确的密度。
- 结果保留两位小数并显示单位。
- 质量或体积不大于 0 时不会进行除法。
- 变量命名清楚，代码能够直接运行。

## 建议文件名

`density_calculator.py`

把计算结果与铝（2.70 g/cm³）、铁（7.87 g/cm³）和铜（8.96 g/cm³）的密度比较，输出最接近的材料。
